# v0.14.0 手机验收

从文件管理打开普通版 APK 覆盖旧版，保留数据。预览版仍是独立数据。

1. **分数明显可见**：已连接账号时，“为你”标题下直接显示“当前标签分数”，包括 0 分。按分数绝对值展示显著倾向，可横向查看所有标签；“查看全部 N 项”直接进入完整分数页。“我的”也有相同入口。普通随机只负责打乱顺序，四连跳换向结合共同跳过标签、分数和手动条件；并不是高分歌曲必定下一首播放。
2. **清分确认**：点“清除当前所有分数”先显示确认，取消不能清除。确认后当前账号全部标签分数立即为 0，分数页同样归零，重开仍为 0；收藏、曲风、历史、熟悉度、明确选歌条件、陪伴时长均保留。随后实际听完 / 快跳的新反馈重新加减分。清分仅清当前账号，不动其他账号或过去换向记录的历史分数快照。
3. **播放中清分**：播放不重启、不暂停、不回到开头。旧四跳累计、旧临时避开及等待确认的换向失效；新的四次有效快跳后再按新分数分析。最近跳过歌曲的防重复仍参考保留的听歌记录。
4. **陪伴时长**：“我的”顶部显示整数分钟，累计本应用实际播放时间，满 60 秒加一分钟；未满一分钟为 0 分钟。正常播放、后台播放、反复听同一首、无标签歌和试听片段都按实际播放时间累计；打开页面但未播放、暂停、加载不计。把进度拖到末尾不会凭空多出时长，系统音频焦点暂停也应停止累计。
5. **保存和升级**：暂停后重开检查分钟数保留，继续播放后累加，不重复计入历史。切换 QQ 账号不清设备内的累计分钟；清标签分数也不影响它。升级首开会按仍保留的原生播放器历史补记一次，已淘汰历史和过去未记录的播放时间无法恢复；以后不再受 500 条历史限制。正常暂停/服务退出保存，播放中每 15 秒保存；异常杀进程至多丢失最后不足 15 秒。卸载应用仍会删除本地数据，因此使用覆盖更新。

自动化验证覆盖旧历史默认评分、清分持久化/账号隔离/后续反馈、旧记录保留、500 条上限、清分后真实排序、快跳重置、单调时钟累计/暂停/重复回调/长时间未观察、一次性历史恢复、页面确认流程和分钟实时显示。页面截图使用虚构曲库，系统后台行为仍需按第 4 项真机核对。
