# v0.10.0 手机验收：缺失曲风处理与收藏外发现

沿用固定签名覆盖安装，不清空已取得的曲风、收藏或旧历史。用户已反馈 v0.9.0 收藏 278 首、曲风 241 首；该数量不是分类准确率。

## 收藏曲风

1. 打开“收藏”，检查已有曲风、等待查询、待重试、暂无资料四组数量之和等于收藏总数。现有正标签保留；旧版本网络错误与无资料缓存分别兼容为待重试和暂无资料。
2. 等待当前分析结束，点击“重试未取得曲风的歌曲”。只安排没有标签的收藏，绕过它们的旧等待期，不重新查询已取得标签的歌曲。失败时保留待重试，来源确实无资料时保留未知，不承诺全部变为已识别。
3. “待补齐”包含所有未取得标签的歌曲；横向筛选栏还可单独查看待重试、暂无资料。每行显示相应状态，实际正在查询的行有提示。
4. 列表展示最多两个曲风名及剩余数量；展开播放页可查看全部标签。补充资料仍仅用于 QQ 缺失曲风的歌曲，没有扩大成歌手风格或情绪猜测。

## 自动发现收藏外歌曲

1. 账号收藏可用时，无须先点“继续这个感觉”，即从收藏选择种子、获取 QQ 相关歌曲元数据。优先覆盖不同已知曲风和近期正反馈，避开近期负反馈。
2. 每个账号进程内自动预取至多六个收藏种子；新账号尚无曲风时先取两个，分析后可补足。当前播放歌曲也会请求自己的直接相关候选。只读元数据，不批量取得音源。
3. 首页显示“收藏外候选”数量、发现状态；“发现更多”从其他尚未缓存的收藏再选至多六个种子。收藏外候选不等于用户从未听过；熟悉/探索仍按收藏和本机记录判断。
4. 成功返回（含空结果）按种子缓存 24 小时，失败后等待 15 分钟；请求串行、间隔 1.2 秒。已有候选在接口失败时保留。
5. 候选及直接关系按账号保存，重开应用后仍在；切换账号不可混入旧账号候选。磁盘只保留最近 24 批，每批最多 30 首，重复歌曲按 MID 合并。没有保存 Cookie、音源链接或推断曲风。

## 未知曲风推荐和真实队列

- 对无标签的收藏点“继续这个感觉”：QQ 若返回直接相关候选，即使该歌或候选缺标签，也可出现“QQ 相关歌曲 · 曲风待补齐”推荐。不得把共同歌手、间接关系或反向关系当成依据。
- 已知曲风明显冲突的候选仍不通过这条回退路线；近期跳过的歌仍排除。没有 QQ 直接关系、又没有共同曲风的歌不会被填进列表。
- 点“播放这批”后，下一首应来自这批推荐；点其中一首应从选定位置继续该批顺序，不能重新接回收藏顺序。实际播放仍受 QQ 账号权益和音源可用性约束。
- 四次快跳换方向仍仅使用已知曲风，未知标签不等于“其他曲风”。冷却、自动切换不记负反馈、试听/错误处理维持 v0.9.0 规则。

本地自动化验证状态迁移、重试不改正标签、精确关系与缓存上限、种子选择、回退过滤、页面与批次播放入口。真实账号新增候选覆盖率、音源和系统后台行为需要手机验证。没有新增声音/情绪模型。
