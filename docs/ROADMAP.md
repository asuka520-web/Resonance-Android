# 共鸣待做清单

按 2026-11-17 用户要求记录；优先保证手机选歌主线，PC 仅作验证。

已完成本轮：

- [x] 动态加权随机：显示分数参与后续排列，不中断当前歌；可清分，保留中性探索与上一首。
- [x] 主动曲风反馈：多来这种 / 暂时少放，明确选择实际标签，独立于 QQ 收藏和真实听歌记录。
- [x] 整库单标签自动补充与缓存续查；同义标签统一，不保证所有歌曲都能取得更多资料。
- [x] 严格匹配录音的社区情绪 / 乐器线索单独展示，注明来源与门槛。
- [x] 克制直接的日常文案：相似推荐 / 随心听。
- [x] 四次快跳无候选时也保存原因。换批把与快跳歌曲差异更大的候选排在前面，手动拖动进度不会触发换向成功提示。
- [x] 「发现更多」额外读取可访问的 QQ 歌单，按账号缓存歌曲资料并显示来源。实际可播性仍需用手机核对。
- [x] 电脑端首次实测 5 首有许可的真实录音，记录了节拍误差和标签误判。见 [声音分析实验](../experiments/audio-tagging/README.md)。
- [x] 实测双算法节拍复核和同标签按速度排序，加入中式配乐及普通话原声／混音样本。测量和排序只在电脑实验中运行。

待完成：

- [ ] **扩大声音分析评估**：加入有参考 BPM 的普通话歌曲和人工听感参考，测量倍速误判、曲风、力度和乐器识别。双算法仍可能把 60 BPM 同时判成 120 BPM；普通话试验样本没有公开参考 BPM。
- [ ] **手机端音频采样与耗电 / 流量测试**：优先复用正在播放的解码数据或有界缓存，不批量下载收藏，不上传音频；模型体积、许可证、耗时、温升、功耗及后台稳定性均须通过。
- [ ] **将声音特征接入推荐与当前倾向**：区分曲库曲风、社区标注、模型推测；仅在前两项验证后启用，未知特征不假匹配。“不喜欢这首”与“当前少听某种听感”分别学习。
- [ ] **更丰富的收藏外发现来源**：目前使用 QQ 直接相关歌曲及账号歌单。其他目录搜索来源仍待接口及账号可播性验证。
- [ ] **网易云收藏、歌单及应用内播放**：已有网页登录入口，下一步需要开放平台批准的能力范围和接口说明。见 [网易云接入说明](NETEASE_INTEGRATION.md)。
- [ ] **补充来源扩展**：目前仍只有 QQ 主资料与 MusicBrainz 严格录音。需要密钥的来源不得偷用公开密钥；专辑 / 歌手标签不得自动替代单曲。验证新的精确来源后再接入。
- [ ] **听感线索参与选歌的验证**：当前社区描述只单独展示，不进入曲风分数或自动换向。需要评估覆盖率、误标和与用户实际意图的关系后决定是否加入。

持续手机验收：在真实收藏上验证连续四次快跳、实际播放目标、最近换向记录和短期去重，核对发现页 QQ 歌单来源与可播性，并在 vivo 通知栏和锁屏复测「上一首」。QQ 收藏读回、后台分钟计时、动态随机及覆盖升级也保留为真机检查项。
