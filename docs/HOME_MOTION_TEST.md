# Resonance 首页动效验收

时长、曲线和降级门槛集中在 `ResonanceMotion.kt` 的 `Motion` 对象。沙粒目标点仍按歌曲 ID 生成，推荐设置和音源接入沿用原有逻辑。

| 要验证的效果 | 手机上的操作 | 预期 |
| --- | --- | --- |
| 冷启动与切歌 | 从系统最近任务移除应用后打开「为你」。播放一首歌，停留在共振板可见处，点迷你播放器的「下一首」。 | 冷启动从板上沿落下。切歌从上一个图案散开，再聚成新图案。真实封面就绪后交叉淡入。来回切换底栏不重复冷启动落沙。 |
| 播放微震与标志 | 停留在首页顶部，点播放，再点暂停。 | 暂停后沙粒在约 300ms 内停住，标志在约 250ms 内恢复。电平来自模拟信号。 |
| 分数、双向条和敲击 | 在标签已有非零分数时点「清除」并确认。也可通过歌曲详情的「多来这种」或「暂时少放」调整真实分数，再回到首页。 | 可见分数和刻度向新值过渡。共振板可见时敲击并回弹。推荐结果目前没有公开 0–1 相似度，清晰度固定使用 0.5，调试时可以修改 `HomePlate` 的 `match` 参数验证过渡。 |
| 换一批 | 先点「相似推荐」产生候选，滚到推荐列表。点「换一批」，选几首没有真实封面的歌观察占位图。 | 占位图依次散开、淡出，再聚拢。不同的真实封面交叉淡入。行的位置保持不动。现有引擎可能返回相同候选。 |
| 按键、图标、导航和进度 | 按住任意首页按钮再松开，点播放／暂停，在底栏切换栏目。播放时留在「为你」观察进度线，再拖动完整播放器里的进度条。 | 按钮回弹，播放图标在三角与双竖条间变形，导航胶囊滑向选中项。正常播放时进度线匀速推进，拖动进度后跟随跳转。 |
| 停帧与减少动态效果 | 播放时将共振板完全滚出屏幕、切到其他栏目、切出应用或锁屏。再把系统的动画时长比例设为关闭，重复切歌和换一批。 | 板不可见时停止更新沙粒，应用失焦或熄屏时停止首页帧循环。系统动画关闭时直接显示终态。 |

真机性能可在系统跟踪中查看 `ResonanceSandPlate`，目标为单次绘制提交不超过 4ms。共振板绘制或窗口帧工作连续 6 次超过 14ms 时，本次首页会话把板的更新上限降到约 30fps，并将板上的 2060 粒减为 1030 粒。
