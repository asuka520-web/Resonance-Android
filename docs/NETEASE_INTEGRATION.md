# 网易云音乐接入

## 当前状态

- v0.15.10 提供「我的 → 网易云音乐 → 登录 / 管理账号」，打开网易云官方网页。会话与 QQ 音乐分开保存。Android 8 由系统浏览器打开。真机网页登录仍待确认。
- 共鸣的曲库和播放器目前从 QQ 音乐取得数据与音源。网易云的收藏、歌单和共鸣内播放还缺平台授权及对应的接入说明。

## 接入所缺的资料

网易云官方 `ncm-cli` 文档将开发者应用配置和用户登录授权列为两个步骤。文档介绍了歌单等操作，播放部分说明了桌面播放器的用法。共鸣需要开放平台批准的接入方式，以及能读取「我喜欢」、用户歌单并在 Android 应用内播放的接口或 SDK 文档。当前公开资料没有确认此应用可以取得这些权限。 [官方接入说明](https://github.com/NetEase/skills#前置条件) · [官方 CLI 播放说明](https://github.com/NetEase/skills/blob/master/netease-music-cli/SKILL.md)

有开放平台应用资格或现成的授权服务时，先确认获批的能力和接口文档。开发者私钥只配置在受信任的服务端，用户在官方授权页自行确认。 [网易云开放平台申请入口](https://developer.music.163.com/st/developer/apply/account?type=INDIVIDUAL)

## 拿到授权后的实现顺序

1. 接上官方授权，用接口返回的用户身份确认授权状态。网易云与 QQ 的歌单、歌曲 ID 和缓存各自按账号区分。
2. 从「我喜欢」和一个自建歌单各同步一页，再核对歌曲总数、翻页顺序和重复项。先做只读同步。
3. 选一首账号有权播放的歌曲，在共鸣播放器内核对正确歌曲的播放进度、暂停和恢复。按授权范围处理受限歌曲；试听只记为试听。

现有网页入口在 `NetEaseAccountActivity`，播放器入口在 `ResonancePlaybackService`。完成上述链路前，网页保持独立入口，网易云歌曲不会进入共鸣的原生队列或推荐库。
