## Android v0.7.0

- 增加真实公开曲风查询：点击后向 MusicBrainz 发送所选歌名和歌手，核对录音版本后读取录音级曲风；不上传历史或歌词。未收录或无标签时保持未知。
- “我想继续听这类歌”：按已核对曲风重合、近期/长期正反馈及重复惩罚，从本机已识别曲库推荐其他歌曲，展示理由。
- 连续四次快跳后分析共同曲风；只有至少三首共有标签且四首资料齐全时才选择其他方向，保持 120 秒冷却。
- 候选目标为 70% 本机有记录 / 30% 本机尚无记录；不足时展示实际数量，不虚构陌生曲库。
- 增加公开队列与选曲能力读取、目标选曲请求及实际播放确认。准确目标 ID 必须持续播放并跨越两次轮询，10 秒未确认即报超时，不循环跳歌。
- 新自动播放开关默认关闭，旧模式设置不会偷偷开启控制；推荐操作产生的切换不记作你的负反馈。
- 保留旧记录、标注和签名；JSON schemaVersion 仍为 3，新增可选 trackFeatures 字段。

**范围与待验收**：推荐只覆盖本机已识别且有录音曲风的歌曲。尚无全量 QQ 目录、音频/情绪/节奏识别；QQ 音乐是否接受指定播放请求需在手机上验证，界面不会把发出请求称为播放成功。

[v0.7.0 手机测试步骤](https://github.com/asuka520-web/Resonance-Android/blob/main/docs/CORE_FEATURE_TEST.md)

## 保留 v0.6.2 的歌曲识别

- 自动解析经真机验证的 QQ 音乐“歌名-歌手”ARTIST 字段，稳定后缓存歌名、歌手、专辑。
- 人工标注优先；歌词字段不作自动歌名；歧义或变化字段要求人工核实。

## 安装与更新

- `Resonance-latest-debug.apk`：普通版，包名 com.resonance.app。
- `Resonance-preview-debug.apk`：可并行安装的“Resonance 预览版”，包名 com.resonance.app.preview。
- 预览版可与旧版共存，数据分开保存，需要单独开启通知读取权限，不会自动迁移旧记录。

当前 v0.6.2 及后续构建固定使用同一 Android 签名，已迁移至 GitHub 加密 Secret，不再依赖临时缓存。
构建会核对公开证书指纹，缺少或不匹配就停止打包，不自动生成新签名。
未来同一包名、相同签名且版本号不降低的 APK 可继续覆盖更新。

早期云端构建使用了未保存的其他签名，不能靠统一新签名补救其覆盖升级。
如果普通版提示签名冲突，不要清数据或卸载旧版；先使用并行预览版验证。
