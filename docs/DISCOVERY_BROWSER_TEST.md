# v0.11.0 手机测试

沿用同一签名覆盖更新。从手机“文件管理 → 下载”打开普通版 APK，保留已有收藏、标签和历史。预览版仍是独立包。

## 发现栏目

- 底部有“为你 / 发现 / 收藏 / 我的”。首页点收藏外候选数量也进入发现；切换栏目返回顶部。
- 发现展示收藏外的可浏览歌曲、曲风及直接相关推荐来源。来源按已缓存的 QQ 种子关系显示；没有种子歌名时明确说明来源不可显示，不编造关系。
- 搜索歌曲、歌手、专辑；按曲风筛选；“仅看本机无听歌记录”排除本机已记录歌曲，不声称你从未在其他地方听过。
- 默认过滤近期十条中的负反馈、已收藏歌曲和有明确录音 ID 的重复版本。按近期正反馈曲风及种子关联排序，并分散歌手；不会据歌手推断曲风。
- 点“播放前 N 首”播放当前结果前最多 100 首；点任意歌曲，从含该歌的最多 100 首窗口对应位置开始。下一首对应队列中的下一首，搜索或更新候选不应突然重排已开始的队列。
- “发现更多”维持 v0.10.0 的元数据缓存、限速和账号隔离。实际音源仍按 QQ 账号权益获取。此栏目不是 QQ 账号的每日推荐接口，也未增加声音/情绪模型。

## 四次快跳后的等待

1. “我的 → 换方向后的等待”默认为“不额外等待”。原生播放器仍需要每首实际开始播放、连续四次有效快跳和足够可靠的曲风/目标，才尝试换向。
2. 换向后再次人工连续快跳四首，不应再被原来的 120 秒阻止。自动替换、错误、试听和未实际听过的连续点击不算有效快跳。
3. 可选 15、30、60、120 秒；设置保存，下一次切歌立即应用，不必重开。选择额外等待时按设定等待再允许触发。
4. 无标签或没有其他曲风时仍明确说明原因；缩短等待不意味着允许拿未知曲风当成相反方向。旧版监听页面不受本项变更影响。

## 曲风重试与换来源

- 收藏曲风统计旁可见两个按钮：重试未取得曲风、换来源补齐。初始分析正在进行时也可安排，安排后显示“重试已安排…”。已有标签不进入缺失重试。
- 普通重试先 QQ，再尝试 MusicBrainz；QQ 空标签和读取错误都可进入补充查询。补充只发送歌曲元数据，不发送账号凭据或历史。
- “换来源补齐”本轮跳过 QQ，直接对缺失歌曲严格核对补充曲库录音。网络失败保持待重试；不唯一或无曲风保持暂无资料，不自动选看起来相似的版本。
- “我的”关闭在线补全时，换来源按钮禁用且说明开启位置；普通重试仍可查 QQ。三个连续来源失败会暂停，避免无限重试；已取得的曲风在失败/空刷新时保留。
- 开发机用可控来源模拟覆盖了 QQ 错误回退、关闭开关、取消、无资料与网络失败差异、已有标签保留。实际 37 首能补齐多少取决于真实曲库资料，需要真机观察。
